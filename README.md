# NodeHero ⚡  
*A fun introductory Node.js + Express project that generates a random superhero name and serves it on a web page.*

---

## 🧠 Overview  
NodeHero is a simple web server built with **Node.js**, **Express**, and the **superheroes** npm package.  
Each time a user visits the server’s root route (`/`), the app responds with a dynamically generated superhero name.

This project demonstrates your understanding of:
- Basic Express routing  
- Using third-party npm packages  
- Creating a simple HTTP server  
- Modern JavaScript module imports  

Perfect as a first Node.js project.

---

## 🚀 Features  
- Random superhero name generator  
- Lightweight Node.js server  
- Fun, dynamic HTML response  
- Clean ES module syntax (`import`/`export`)  
- Powered by the popular `superheroes` npm package  

---

## 🛠️ Technologies Used  
- **Node.js**  
- **Express.js**  
- **NPM** (`superheroes` package)  
- **JavaScript (ES Modules)**  

---

## 📦 Installation & Setup  

1. Clone the repository  
```bash
git clone https://github.com/<your-username>/NodeHero.git
cd NodeHero
```

2. Install dependencies  
```bash
npm install
```

3. Run the server  
```bash
node index.js
```

4. Visit in your browser  
```
http://localhost:3000
```
